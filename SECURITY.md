# Security

Report a vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/nabinpkl/rags/security/advisories/new)
for this repository, not as a public issue.

In scope: the API, the agent's tools and sandbox, prompt injection through
retrieved paper text, the spend caps, and anything that would let the app
return more of a paper than its quote limits allow. The threat model is §6 of
the [design spec](docs/superpowers/specs/2026-07-04-agentic-rag-design.md).
